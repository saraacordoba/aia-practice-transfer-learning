# Transfer Learning con CNNs - Dataset Flowers (AIA 2025-2026)

Este repositorio contiene las prácticas correspondientes a la **Parte 2 de la asignatura AIA** (Grado en Ingeniería Informática - Tecnologías Informáticas, Universidad de Sevilla).

## Contenido
* **Modelo 1 y 2:** Construcción e implementación de una CNN básica desde cero y técnicas para mitigar el sobreajuste (*overfitting*).
* **Modelo 3:** Aplicación de *Transfer Learning* utilizando una red preentrenada sobre el conjunto de datos de flores (*Flowers Dataset*).
* **Exploración de datos:**
  * Inspección de archivos individuales del dataset.
  * Conteo y distribución de imágenes por clase (`daisy`, `dandelion`, `roses`, `sunflowers`, `tulips`).
  * Visualización y comprobación de *shapes* de las imágenes.

## Requisitos e Instalación
* Python 3.x
* TensorFlow / Keras
* NumPy, Matplotlib, PIL
